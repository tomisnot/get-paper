# PaperPilot 使用指南

PaperPilot 是论文情报和研究工作台。它负责获取论文、按研究主题筛选、准备评审材料、保存 AI 或人工判断、生成简报，并提供检索、精读、笔记、标签和引文追溯。

## 日报流程

~~~text
fetch_papers -> prepare_review -> 外部 AI 或人工评审 -> submit_review -> finalize_briefing
~~~

fetch_papers 根据启用主题、时间窗口和来源建立候选池。prepare_review 返回论文、正文引用、规则分、匹配依据和评审契约。submit_review 保存结构化判断。finalize_briefing 根据已保存评审和策略生成日期简报。确定性基线可以执行规则筛选，但不会冒充模型判断。

## 主题与画像

query_topics 查看主题；set_topic_enabled 控制抓取。主题包含关键词、分类、作者和窗口。已读、星标、跳过、标签和评审信号会进入画像权重，影响后续排序。修改主题后先查询，再抓取；不要用显示名代替 topic id。

## 检索与精读

- search_papers：按关键词、主题、状态和时间分页；
- read_paper：读取元数据和评分；
- read_paper_text：按块或范围读取正文；
- paper_metrics：读取影响力字段；
- read_references/read_citations：读取引文关系；
- search_text：搜索已建立的全文索引。

正文先搜索和定位，再按段读取。外部下载受网络、速率和缓存影响。

## 阅读沉淀

mark_read、star_paper、set_marked_skip、add_note、delete_note、add_tag 和 set_tags 都会形成可追溯操作。保留回执中的 seq 或 operation_id，方便以后查看理由和修改。

## 评审

prepare_review 给出当前候选和字段要求。提交至少包含论文 id、相关性分、标签、理由和必要摘要。只提交回执中的候选，不猜缺失论文。不能判断时返回低置信度或人工复核标记。

## 简报

finalize_briefing 按日期生成简报和卡片。它消费已保存评分、评审、摘要和排序策略。重新生成不会改论文原始事实；要改变结果，先改评审、主题或策略。

## 引文图

图视图保存节点、边、年份、过滤条件和默认视图。单篇论文用 read_references/read_citations；upstream_clusters 和 related_by_cocitation 用于聚类和共引。图是研究辅助视图，缺失关系可能来自外部来源限制。

## AI 边界

AI 评审由外部调用方完成，软件提供依据、检查结构、保存结果并生成派生简报。baseline 是确定性路径，回执会标明来源。提交前确认论文 id、引用、分数、理由和标签完整。

## 操作和错误

写操作经过 Scope 和 Gate。错误回执包含 kind、hint、suggest，优先按建议查询或补充数据。undo/reset 生成新的事实并更新当前状态，不直接删除。活动页可查看操作者和理由。

## 性能

列表使用 limit、cursor 和分页；正文按块读取；引文限制数量；大批量抓取放后台；外部 API 使用缓存和速率；评审分批提交。不要一次把整批论文、全文和图装入 AI 上下文。

## 常见问题

- 没有候选：检查主题启用、窗口、分类、去重和来源状态；
- 评审失败：使用 prepare_review 的 id 和契约，检查字段；
- 简报为空：确认评审已保存且状态符合策略；
- 正文失败：查看下载和索引状态，先重试单篇；
- 图不完整：查看来源和 coverage，外部服务可能没有全部边。

## 最小路径

配置数据根和主题；query_topics；fetch_papers；search_papers；prepare_review；人工或外部 AI submit_review；finalize_briefing；对重点论文 read_paper_text、add_note、set_tags；最后用引文查询扩展研究网络。
