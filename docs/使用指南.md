# PaperPilot 使用指南

PaperPilot 是面向科研人员的论文情报和研究工作台：抓取论文、按研究画像筛选、准备评审材料、接收 AI 的结构化判断、生成简报，并支持检索、精读、笔记、标签和引文追溯。

## 日报流程

```text
fetch_papers → prepare_review → 外部 AI 评审 → submit_review → finalize_briefing
```

`prepare_review` 返回候选论文、规则分和评审契约；AI 逐篇判断后一次性提交。`finalize_briefing` 根据已保存的评审生成简报。没有外部 AI 时，确定性基线仍可供人和调度器运行，但不会冒充模型判断。

## 研究工作流

- `search_papers`、`read_paper`、`read_paper_text`：检索和精读；
- `mark_read`、`star_paper`、`add_note`、`add_tag`：沉淀阅读状态；
- `paper_metrics`、`read_references`、`read_citations`：查看影响力和引文关系；
- `query_topics`、`set_topic_enabled`：维护研究画像和主题池；
- Web 页面用于浏览、下载、简报、设置和活动记录。

大列表使用分页游标；正文和长结果使用块、偏移或产物引用读取。写入回执包含实际落地内容和操作关联，失败回执带 `kind`、`hint` 和 `suggest`。

## AI 评审注意

评审判断属于外部 AI 的工作，软件只负责提供依据、校验结构、保存判断和生成派生简报。提交前确认论文 id、评分、标签、理由和必要摘要齐全；需要继续时使用上次回执中的游标或剩余项。
