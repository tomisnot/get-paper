## 1. 总纲：图 = 一等公民，网络 = 实例

现在的实情：`infra/orm.py::CitationEdge` 是事实上的图存储，`app/web.py::network` 是唯一的图消费方，且**布局、分层语义、跳转策略、富化全部硬编码在那一个路由里**。下一个"共引相似图""主题关系图"要么复制这 100 行，要么重复踩坑。

**底座五层（自底向上）：**

```
F1 图数据模型    nodes/edges/权重 → 与领域无关的 dict 形状
F2 布局引擎      nodes+edges → 坐标（层号=拓扑深度；无限层；层状布局）
F3 节点句柄      id → 本站论文面（不存在先入库）；一律站内闭环
F4 富化协议      node → label + hover 卡片（内容来自卡片系统，图只做呈现）
F5 参数化        布局/富化参数进 settings.yaml + /settings 面板
```

## 2. F1 图数据模型（与领域无关）

```python
# domain/graph.py（新，纯函数域层，零 IO）
@dataclass(frozen=True)
class Node:
    id: str                      # arxiv_id 或任意实体键
    kind: str                    # 呈现分类："src" | "dst" | "entity"（由消费方定义）
    label: str                   # 显示名（由 F4 生成）
    weight: float = 0.0          # 主权重（消费方给语义：被引数/画像分/度）
    degree: tuple[int, int] = (0, 0)   # (in, out) 度——布局与大小的几何输入
    meta: dict = field(default_factory=dict)   # 领域负载（引用数/入库否/论文对象...）

@dataclass(frozen=True)
class Edge:
    src: str
    dst: str
    weight: float = 1.0
    kind: str = ""               # 呈现分类（如 influential）
```

**契约**：`CitationEdge` → `Node/Edge` 的转换是**消费方适配器**（引文网络适配、共引图适配各一个），域层不认识"引用"。

## 3. F2 布局引擎：层号=拓扑深度，无限层

- 输入 `nodes/edges` 与一组**源节点**（有指向外的出发集合，如"在库论文"）；
- **层号 = 从源集出发的最短路径长度**（BFS 反向，即 dst 按其到源的距离分层）。图有 9 层就画 9 层，**层数不可配置**——配置层数=特化；
- 层内 x 坐标按 `degree.in` 降序散布（被越多上游指向越靠中/越大）；
- 边只画「相邻层」之间（跨层边折叠为穿层弧线，层数 >6 时自动只画相邻层防织网）；
- **时间映射为可选**：`layout.sort_within = "weight" | "year"`，缺省 weight。用户明说"不一定按时间”；
- 层带/分隔线是可选渲染参数，不是算法的一部分。

**验收判据**：构造一条 4 层链 + 一个跨层 shortcut，输出层号集合 = {0,1,2,3}，shortcut 不产生新层；同输入必同输出（确定性，同 feed）。

## 4. F3 节点句柄：点击 = 入库 + 进本站论文面

- `Node.id` 是 arxiv_id 时，点击行为统一为：
  1. 不在库 → `fetch_paper_by_id`（幂等、走命令面、带 reason）；
  2. 302 到 `/papers/{id}`（本站论文详情/管理面）；
- **永不外跳 arXiv**（外跳只保留在论文详情页的"原文/PDF"按钮——那是有意漏斗，要记 outbound 信号）；
- 入库失败（arXiv 炸了）→ 节点 tooltip 显示"入库失败：<原因>"，页面不白屏；
- 非论文实体（未来：主题节点、作者节点）走各自句柄，协议同名。

**验收判据**：图谱有 10 个未入库上游 → 逐个点击后 10 篇全在库、10 条 fetch 事件带 actor/reason、无一次外跳。

## 5. F4 富化协议：图不生产内容

```
label(node) = shorten(node.meta.get("title") or node.id, max_len=N)
              N 由 settings 图配置给（默认 18），超长补省略号

hover_card(node) = {
    "title": 全标题,
    "body": 卡片系统视图——有 summary 卡 ⇒ 五段 + score/label/reason；
            无卡 ⇒ "未入库，点击入库后由 AI 补卡"/S2 摘要,
    "facts": 消费方给的数字行（被引/同引/画像分…）,
    "url":  F3 句柄
}
```

- **呈现层零内容生产**：所有文字来自 cards（paper_summaries）/ paper_metrics / 消费方 meta；
- 渲染为服务端 SVG 内嵌 `<foreignObject>` 或 hover 显现的 hidden div（**零 JS**，与本页现风格一致）；
- 富化协议供所有图实例复用（引文网络、共引相似、未来的主题谱系）。

**验收判据**：库内节点 hover 展示 tldr 五段卡；未入库节点 hover 展示 S2 标题+被引+“点击入库”；label 超 18 字符截断且 tooltip 保留全称。

## 6. F5 参数化（settings.yaml → /settings）

```yaml
graph:                      # 新增段，所有图实例共用
  max_label_len: 18
  layer_gap: 110             # 层间距 px
  node_gap: 90               # 层内间距
  size_by: "degree"          # "degree" | "weight" | "flat"
  color_by: "kind"           # "kind" | "in_lib" | "weight"
  sort_within: "weight"      # "weight" | "year"
  max_nodes: 60              # 保护：抽样规则=每层按 degree top-K
```

- `/settings` 增“图谱”卡，改动写 YAML、热生效于下次渲染；
- **所有默认值可由消费方覆盖**（网络页可给自有缺省，但用户可改）。

## 9. 明确不做

- 不做力导向物理仿真（层状已满足"无限分层+几何"，力导向的抖动破坏可复算性）；
- 不做交互式缩放/拖拽前端（引入 JS 依赖，违背零依赖家规；参数化已覆盖表达力）；
- 不给层起业务名（"奠基层/中坚层"是任务特化，用户已明确否决）。
